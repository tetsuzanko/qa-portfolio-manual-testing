# Test Plan

## 1. Цель

Проверить основные пользовательские сценарии интернет-магазина и выявить дефекты, которые мешают корректному выбору товара, работе корзины и оформлению заказа.

## 2. Scope

### In scope
- Карточка товара
- Выбор размера
- Выбор цвета
- Количество товара
- Корзина
- Расчёт суммы
- Авторизация в контексте оформления
- Оформление заказа

### Out of scope
- Реальная оплата
- Интеграции с внешними платёжными системами
- Нагрузочное тестирование
- Безопасность
- Мобильные приложения

## 3. Test approach

Используются:
- функциональное тестирование;
- позитивные и негативные сценарии;
- анализ граничных значений;
- классы эквивалентности;
- smoke-проверки;
- регрессионные проверки затронутых областей.

## 4. Test data

Размеры: S, M, L, XL  
Цвета: чёрный, белый  
Допустимое количество: 1–5

## 5. Environment

Browser: Google Chrome  
Platform: Web application

## 6. Entry criteria

- Доступно тестируемое веб-приложение.
- Доступны тестовые данные.
- Основные функции приложения доступны для проверки.

## 7. Exit criteria

- Выполнены запланированные проверки.
- Все обнаруженные дефекты зарегистрированы.
- Для дефектов определены Severity и Priority.
- Подготовлен итоговый отчёт.
