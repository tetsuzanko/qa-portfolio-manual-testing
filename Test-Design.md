# Test Design Examples

## 1. Boundary Value Analysis

Для поля количества товара допустимый диапазон: 1–5.

Проверяем:
- 0 — ниже минимума;
- 1 — минимальная граница;
- 3 — типичное значение;
- 5 — максимальная граница;
- 6 — выше максимума.

## 2. Equivalence Partitioning

Количество товара можно разделить на классы:

| Класс | Примеры | Ожидание |
|---|---|---|
| Недопустимый ниже диапазона | 0 | Ошибка / запрет |
| Допустимый | 1–5 | Значение принимается |
| Недопустимый выше диапазона | 6+ | Ошибка / запрет |

## 3. Positive Testing

Пример:
Выбрать размер XL, цвет чёрный, количество 5 и добавить товар в корзину.

Ожидание: товар добавляется с указанными характеристиками.

## 4. Negative Testing

Пример:
Попытаться установить количество 6.

Ожидание: система не принимает значение выше максимума.

## 5. Почему техники важны

Техники тест-дизайна помогают уменьшить количество проверок и одновременно повысить вероятность обнаружения ошибок на границах допустимых значений.
