# QA Portfolio — Станислав Семёнов

## Junior Manual QA

Учебный проект по ручному тестированию веб-приложения интернет-магазина.

### О проекте

Цель проекта — отработать полный базовый цикл работы Junior Manual QA:
1. Анализ требований и пользовательских сценариев.
2. Подготовка тестовой документации.
3. Проведение позитивного и негативного тестирования.
4. Применение техник тест-дизайна.
5. Фиксация фактических результатов.
6. Регистрация и приоритизация дефектов.
7. Подготовка итогового тестового отчёта.

### Проверяемые области

- Авторизация
- Карточка товара
- Выбор размера и цвета
- Количество товара
- Корзина
- Расчёт итоговой стоимости
- Оформление заказа

### Используемые техники

- Equivalence Partitioning
- Boundary Value Analysis
- Positive Testing
- Negative Testing
- Functional Testing
- UI Testing
- Smoke / Regression concepts

### Артефакты

| Файл | Содержание |
|---|---|
| `Test-Cases.xlsx` | Тест-кейсы и результаты выполнения |
| `Checklist.xlsx` | Чек-лист основных проверок |
| `Bug-Reports.xlsx` | Зарегистрированные дефекты |

| `Test-Report.md` | Итог по выполненному тестированию |
| `Test-Design.md` | Примеры техник тест-дизайна |

### Результаты

В рамках учебного проекта зарегистрированы дефекты, связанные с:
- расчётом итоговой суммы;
- отображением выбранного размера;
- количеством товара в корзине;
- оформлением заказа.

> Это учебный проект. Он не представляет коммерческий опыт работы в QA.
