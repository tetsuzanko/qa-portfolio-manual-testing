Тестирование голосового ассистента Алиса

О проекте

Учебный проект по ручному тестированию голосового ассистента и элементов пользовательского интерфейса.

Цель тестирования

Проверить корректность обработки голосовых запросов, содержание ответов и отображение элементов интерфейса.

Область тестирования

* Запросы времени и даты.
* Запросы о погоде.
* Музыкальные команды.
* Отображение карточек, ссылок и кнопок обратной связи.
* Проверка интерактивных голосовых сценариев.

Артефакты

* Тест-кейсы.
* Баг-репорты.
* Отчёт о результатах тестирования.

Навыки

* Функциональное и UI-тестирование.
* Составление тест-кейсов.
* Описание и документирование дефектов.
* Анализ ожидаемого и фактического результата.
* Работа со статусами Passed, Failed и Blocked.
* Ведение тестовой документации в Excel.

Тип проекта: учебный проект по Manual QA.
